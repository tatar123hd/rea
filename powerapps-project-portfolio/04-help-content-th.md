# ส่วนที่ 4 — เนื้อหาคู่มือในแอป (ภาษาไทย)

ไฟล์นี้คือ **ต้นฉบับ** ของข้อความที่แสดงในหน้าจอ **คู่มือการใช้งาน** (`scrHelp`)
แก้ที่นี่ก่อน แล้วคัดลอกไปใส่ในสูตร `htmHelp.HtmlText`

ข้อความเขียนให้ผู้ใช้ที่ไม่ใช่สายไอทีและผู้ใช้สูงวัยอ่านได้: ประโยคสั้น ไม่มีศัพท์เทคนิค
ไม่มีคำว่า delegation / collection / Patch / SharePoint list ปรากฏให้ผู้ใช้เห็น

---

## 1. เริ่มใช้งานครั้งแรก

1. เปิดแอปจากลิงก์ที่ได้รับ
2. ถ้ามีหน้าต่างถามเรื่องการอนุญาตให้เชื่อมต่อข้อมูล ให้กดปุ่ม **Allow**
3. ระบบจะตั้งค่าให้อัตโนมัติ: แผนกของคุณเอง และช่วงเวลาเป็นเดือนปัจจุบัน
4. ถ้าหน้าจอว่างเปล่า ให้กดปุ่ม **ล้างตัวกรอง** แล้วเลือก **ทุกแผนก**
5. เมนูทางซ้ายใช้สลับมุมมอง แถบตัวกรองด้านบนใช้ร่วมกันทุกมุมมอง

## 2. ใช้ตัวกรอง

ตัวกรองอยู่แถบบนสุด และ **ใช้ร่วมกันทุกมุมมอง** เมื่อสลับหน้าจอไปแล้วกลับมา ค่าที่เลือกไว้ยังอยู่

1. เลือกช่วงเวลา: **รายสัปดาห์ / รายเดือน / รายไตรมาส**
2. ใช้ปุ่ม `<` และ `>` เลื่อนไปข้างหน้าหรือย้อนหลังทีละช่วง
3. ปุ่ม **วันนี้** พากลับมาที่ช่วงเวลาปัจจุบัน
4. เลือกแผนก โปรเจกต์ (เลือกได้หลายอัน) เจ้าของโปรเจกต์ ผู้รับผิดชอบ และสถานะ
5. ติ๊กประเภทที่อยากเห็น: โปรเจกต์ / เฟส / งาน / อบรม BAU
6. **กดปุ่ม "ใช้ตัวกรอง" ทุกครั้ง** ข้อมูลจะไม่เปลี่ยนจนกว่าจะกดปุ่มนี้

**ถ้าเห็นแถบสีเหลืองว่าข้อมูลถูกตัด** แปลว่าช่วงเวลาที่เลือกมีรายการมากเกินไป
ให้เปลี่ยนจากรายไตรมาสเป็นรายเดือน หรือเลือกแผนกเดียวแทนทุกแผนก

## 3. อ่านไทม์ไลน์

- แต่ละแถวคือรายการหนึ่ง เรียงเป็นชั้น **โปรเจกต์ → เฟส → งาน**
- กดลูกศรหน้าชื่อเพื่อ **ย่อ** หรือ **ขยาย** รายการย่อย
- แถบสีคือช่วงเวลาของรายการนั้น **กดที่แถบ** เพื่อดูรายละเอียดทางขวา
- **เส้นสีแดงแนวตั้ง** คือวันนี้
- แถบที่มี **ขอบสีแดงและไอคอนเตือน** คือเลยกำหนดแล้ว
- เลนล่างสุดคือ **อบรม BAU** สีของแถบแยกตามกลุ่มหลักสูตร
- แถบที่เป็น **เส้นประสีอ่อน** คือรอบอบรมที่ยัง **รอยืนยัน**

### สีของสถานะ

| สี | ความหมาย |
|---|---|
| เทา | ยังไม่เริ่ม |
| น้ำเงิน | กำลังดำเนินการ |
| เขียว | เสร็จแล้ว |
| แดง | ติดปัญหา |

## 4. สร้างโปรเจกต์ เฟส และงาน

1. ที่หน้าไทม์ไลน์ กดปุ่ม **สร้างโปรเจกต์ใหม่** มุมขวาบน
2. กรอกชื่อโปรเจกต์ เลือกสถานะ แล้วกด **บันทึกโปรเจกต์**
   (ระบบใส่แผนกของคุณให้เอง และบันทึกว่าคุณเป็นเจ้าของ)
3. กดปุ่ม **เพิ่มเฟส**
   - เลือกประเภทเฟส: วางแผน / ออกแบบ / พัฒนา / ทดสอบ / เริ่มใช้งาน / ประเมินผล
   - ใส่ชื่อเฟส วันเริ่ม วันสิ้นสุด
   - เลือกผู้รับผิดชอบ (จะแสดงเฉพาะคนในแผนกเดียวกับโปรเจกต์)
   - กด **บันทึกเฟส**
4. คลิกเลือกเฟสที่ต้องการ แล้วดูคอลัมน์ขวาสุด
   - ระบบแนะนำ **งานมาตรฐาน** ตามประเภทเฟส ติ๊กที่ต้องการแล้วกด **เพิ่มงานที่เลือก**
   - หรือพิมพ์ชื่องานเองในช่องด้านล่างแล้วกด **เพิ่มงาน**
5. **ช่วงเวลาของโปรเจกต์ ระบบคำนวณจากเฟสให้อัตโนมัติ** แก้เองไม่ได้
   ถ้าอยากเปลี่ยนวันของโปรเจกต์ ให้แก้วันของเฟสแทน

## 5. เปลี่ยนสถานะงาน

1. ไปเมนู **กระดานงาน**
2. หาการ์ดงานที่ต้องการ
3. กดปุ่ม `>` เลื่อนไปสถานะถัดไป หรือ `<` ย้อนกลับ

ลำดับสถานะ: ยังไม่เริ่ม → กำลังดำเนินการ → เสร็จแล้ว → ติดปัญหา

**ถ้าปุ่มเป็นสีเทากดไม่ได้** แปลว่าคุณไม่ใช่ผู้สร้างโปรเจกต์นั้น ให้แจ้งผู้สร้างแทน

## 6. งานของฉัน

แสดงเฉพาะ **งานที่คุณถูกมอบหมาย** และ **รอบอบรม BAU ที่คุณเป็นผู้รับผิดชอบหรือ LM**

- **เลยกำหนด** — ต้องจัดการก่อน
- **สัปดาห์นี้** — วันจันทร์ถึงวันอาทิตย์ของสัปดาห์ปัจจุบัน
- **หลังจากนี้** — งานในอนาคต

## 7. ข้อมูลอบรม BAU

- ข้อมูลมาจากระบบ **L&D TMP** แอปนี้ **อ่านอย่างเดียว** แก้ไขที่นี่ไม่ได้
- รายการที่ **ยกเลิก** ถูกซ่อนไว้ เปิดดูได้ด้วยสวิตช์ **แสดงรายการยกเลิก** ท้ายแถบตัวกรอง
- รายการที่ **รอยืนยัน** แสดงเป็นแถบเส้นประสีอ่อน
- กดที่แถบเพื่อดูรายละเอียดเต็ม: รหัสหลักสูตร รอบ ห้อง วิทยากร จำนวนที่นั่ง ระยะเวลา หมายเหตุ
- ถ้าไม่เห็นข้อมูล BAU เลย อาจยังไม่มีสิทธิ์อ่าน ให้แจ้งผู้ดูแลลิสต์ของ L&D TMP

## 8. ใครแก้อะไรได้

| สิ่งที่ทำ | ใครทำได้ |
|---|---|
| ดูไทม์ไลน์ของทุกโปรเจกต์ | ทุกคน |
| สร้างโปรเจกต์ใหม่ | ทุกคน |
| แก้ไขหรือลบโปรเจกต์ เฟส งาน | **ผู้สร้างโปรเจกต์นั้นเท่านั้น** |
| เปลี่ยนสถานะงาน | ผู้สร้างโปรเจกต์นั้นเท่านั้น |
| เพิ่ม แก้ ลบ ทักษะและความสนใจ | ผู้ดูแลระบบเท่านั้น |
| ดูทักษะและความสนใจ | ทุกคน (รวมถึงของตัวเอง — ดูได้แต่แก้ไม่ได้) |
| แก้ข้อมูลอบรม BAU | ไม่มีใครแก้ได้จากแอปนี้ |

ผู้ที่ถูกมอบหมายงาน **ดูได้อย่างเดียว** นี่เป็นไปตามที่ออกแบบไว้ ไม่ใช่ข้อผิดพลาด

## 9. แก้ปัญหาที่พบบ่อย

**หน้าจอว่างเปล่า**
กด **ล้างตัวกรอง** → เลือก **ทุกแผนก** → เปลี่ยนช่วงเวลาเป็น **รายไตรมาส** → กด **ใช้ตัวกรอง**

**ขึ้นว่าโปรไฟล์ไม่มีข้อมูลแผนก**
ฝ่ายไอทียังไม่ได้กรอกแผนกในระบบให้คุณ ระหว่างนี้ใช้ **ทุกแผนก** ไปก่อนได้ตามปกติ
แจ้งฝ่ายไอทีให้กรอกช่อง Department ในโปรไฟล์ Microsoft 365

**กดปุ่มแก้ไขไม่ได้ (ปุ่มเป็นสีเทา)**
คุณไม่ใช่ผู้สร้างโปรเจกต์นั้น

**บันทึกแล้วขึ้นข้อความสีแดง**
ลองกดบันทึกอีกครั้ง ถ้ายังไม่ได้ให้แจ้งผู้ดูแลระบบ พร้อมถ่ายภาพหน้าจอข้อความที่เห็น

**ไม่เห็นข้อมูลอบรม BAU**
ต้องมีสิทธิ์อ่านลิสต์ของ L&D TMP ก่อน แจ้งผู้ดูแลลิสต์นั้นได้เลย

**ขึ้นแถบเหลืองว่าข้อมูลถูกตัด**
ช่วงเวลาที่เลือกมีรายการมากเกินไป ให้ลดช่วงเวลาหรือเลือกแผนกให้แคบลง
ตัวเลขบนหน้าภาพรวมจะไม่ครบถ้ามีแถบนี้

**ปฏิทินไม่แสดงรายการของเดือนที่เปิดดู**
เดือนนั้นอยู่นอกช่วงที่โหลดไว้ ให้กด **รายเดือน** แล้วกด **ใช้ตัวกรอง**
